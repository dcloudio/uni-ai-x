Purpose:
Validate the last T01 feasibility gate with the user's renewed qiniu gateway:
temporary authentication, a real streaming AI request, ArrayBuffer/SSE decode,
incremental Markdown accumulation and CMark parsing.

Scope decision:
- Only qiniu is required for this gate.
- Bailian is explicitly out of scope and was not called in the final run.
- No cloud object was uploaded, deployed or modified remotely.
- The temporary token value is never displayed, logged or persisted. Only its
  length is recorded.

Retained test code:
- Automatic page: pages/repro-worker-real-ai/index.uvue
- Worker scenario: workers/markdownWorkerTask.uts, runRealAiScenario()
- Worker request/SSE core: uni_modules/uni-ai-worker/utssdk
- Snapshot bridge: uni_modules/uni-ai-worker-probe/utssdk
- Route registration: pages.json

Request under test:
- Token provider: qiniu through uni-ai-x-co.getTmpToken()
- Completion endpoint: https://openai.qiniu.com/v1/chat/completions
- Model: deepseek-v3
- stream: true
- Minimum accepted Markdown content length: 800 characters
- Prompt requests 1200-1800 Chinese characters and forbids wrapping the whole
  document in a fenced code block. It requests headings, paragraphs, unordered,
  ordered and task lists, a quote, a table, a JavaScript code block and formulas.

Thread boundary:
1. The page obtains the short-lived token and serializes URL, Authorization and
   request body. This one-time authentication preflight is not claimed to run in
   Worker.
2. WorkerStreamRequest starts the real chunked AI request in Worker.
3. Each received ArrayBuffer goes directly through the stateful UTF-8/SSE decoder
   in Worker.
4. Worker accumulates content and runs CMark every 256 characters and once at
   terminal.
5. The plugin retains the latest immutable snapshot; the page polls every 100ms.

Assertions:
- Temporary token is non-empty.
- The request has network chunks, bytes and SSE events.
- Terminal source is the real [DONE] sentinel.
- Content length is at least 800 characters.
- CMark returns at least one token with no parse error.
- Page reaches the explicit 1/1 terminal summary without timeout.

Evidence boundary:
- This is a qiniu-only Android feasibility gate. Bailian, iOS and Harmony are not
  covered.
- Temporary-token acquisition remains a main-thread preflight. The hot streaming
  request and all response decoding/parsing are the Worker scope validated here.
- The probe uses immutable snapshot polling. Production RequestAiRunner and the
  production render-description builder have not yet been migrated.
- Formula preprocessing and complete production render descriptions are covered
  by deterministic full-chain tests, not by the minimal real-provider assertion.
