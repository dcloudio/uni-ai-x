Purpose:
Validate the production T02 boundary after the separate feasibility gate. The
Android qiniu Worker must assign stable root IDs, group coarse render blocks and
build UI-independent RichText/quote nodes. The main thread must consume the
descriptions in one callback while retaining only viewport/WebView enrichment.

Production boundary:
- Worker: qiniu stream, ArrayBuffer/UTF-8/SSE, Markdown preprocessing, CMark,
  root IDs, seven-kind block grouping and RichText/quote node construction.
- Immutable transport: tokensJson plus renderListJson in the versioned snapshot.
- Main thread: token-object reuse, table viewport sizing, code highlighting,
  MathJax/Mermaid SVG generation and actual component creation.
- UI shells remain native components. Tables/code still use ScrollView and
  toolbars; quote/divider/loading/image containers were not collapsed into two
  component types.
- Old stored messages and non-Android/custom-provider paths keep a main-thread
  fallback because they do not contain production Worker descriptions.
