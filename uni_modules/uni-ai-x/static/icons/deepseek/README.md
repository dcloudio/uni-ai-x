The 29 icons used by this app are stored in components/uni-ai-icon/artwork.uts.
uni-ai-icon renders the original regular SVG geometry as an image Data URL,
substituting currentColor with the control's effective state/theme color.
The icon palette matches static/css/variables.scss. Update both when changing it.

Compatibility reference: uni-app x image documentation, SVG color section;
hello-uni-app-x/pages/component/image/image-path.uvue demonstrates SVG Data URLs.
Native runtime appearance still requires validation on the target device.
