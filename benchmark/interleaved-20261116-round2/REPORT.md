# 三方交叉复测

2026-11-16。开启与关闭深度思考两组各测 5 轮，每轮严格依次完成 Uni AI 网关 → DeepSeek 官方 API → DeepSeek 官方网页，共 30 次请求。使用原有相同提示词，网页每次新建对话。

API 从拿到凭证后发出 POST 开始计时；网页从点击发送按钮开始计时。等待响应为首个非空思考或正文之前的时间；思考阶段为首个思考片段至首个正文；正文输出为首个正文至流式请求结束。Token 获取耗时另存于 results.json，不计入阶段和总耗时。

## 输出与比较范围

30 次请求全部成功完成；其中 30/30 次正文与固定内容逐字一致。每次输出字符数和差异可见 results.json 及对应正文文件。

Uni AI 网关使用 deepseek/deepseek-v4.1-flash，官方 API 使用 deepseek-flash。网页发送 model_type=default，响应未给出具体模型名；无法确认三方实际模型版本及默认推理预算完全一致。思考内容长度不同，不能将思考阶段的全部差异归因于网关转发。

API 首片段按网络到达记录，网页首片段按 DOM 文本首次出现记录，存在计时口径差异；网页网络结束不保证所有公式排版完成。提示词已预热，有缓存命中。固定提示词中两个标题要求互相冲突，原样保留。

原始 API 统计及 SSE 在各 enabled/disabled-轮次-A/B 子目录；网页 SSE、正文和差异文件在本目录。summary.json 提供均值、中位数、最小值、最大值。
