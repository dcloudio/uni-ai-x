# Markdown 真机渲染核对（2026-11-20）

引用块修复已先提交到 `d3335fd`。随后以 `demo/markdown/testMarkdownText.uts` 为基准，在新会话点击“体验完整Markdown示例”，核对首次流式生成的实际界面。

## 发现并修复的额外遗漏

首次生成完成时，任务列表文字、表格标题、引用中的部分正文、代码标题和代数公式标题可能不显示。同一消息重启后恢复；持久化数据完整，不能据此认为首次显示正确。

根因在 `UniAiMdHtmlStreamAdapter.getBlocks()`：连续 HTML 的已提交前缀与未完成尾部在预览时被暴露成两个块。展示层看到后继块后冻结前缀，最终提交又将尾部合回前缀，界面因此保留了不完整的旧前缀。

修复使连续 HTML 的预览和最终提交保持相同的合并关系，使用同一个块及稳定标识。真实的代码、表格、公式边界不变，也不修改展示层冻结规则。继续使用 `rich-text mode="native"`。
