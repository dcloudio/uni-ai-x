# 七牛应用能力接入与实测

核对对象：[DeepSeek 发布全家桶应用 API](https://mp.weixin.qq.com/s/78KBHc4-4N5b2vfL9SkutQ)。
测试日期：2026-11-16。以下结论仅针对本次账号、临时 Token、接口路径和模型的实际结果，不代表七牛所有产品都不支持某项能力。

## 已接入

选择模型 **DeepSeek Flash · 七牛**（`deepseek/deepseek-v4.1-flash`）。原默认提供商配置保留。沿用 UniCloud 获取七牛临时 Token 的机制，不在前端放长期密钥。

| 能力 | 实现与使用 | 实测 |
| --- | --- | --- |
| 阅读链接 / Fetch | 模型调用 `read_web_link`，应用请求 `/v1/tools/fetch`，结果回传模型 | 成功读取上述公众号正文并生成摘要；失败时明确报告工具错误 |
| 联网搜索 / Search | 打开“联网搜索”，模型调用 `search_web`，应用请求 `/v1/tools/search` | 实际返回来源，回答展示引用 |
| 思考模式下搜索 | 同时打开思考和联网搜索，最多五轮模型请求，可反复搜索和阅读链接 | 实际搜索并生成带引用回答；多轮来源去重和编号通过自动化测试 |
| 图片识别 | 复用现有图片上传入口，启用该模型的图片输入能力 | 实际识别合成图片上的唯一编号和数量 |
| ASR / 语音输入 | 点“语音”开始、点“结束”停止；识别文字追加到输入框，由用户编辑发送 | `/v1/audio/transcriptions`、`qwen/qwen-audio-3.0-asr-flash` 实际返回文字；浏览器合成音频流完成录音、WAV 转换、上传及输入框回填 |

搜索和阅读采用应用端 Function Calling 编排，并未证明七牛原样支持官方内置 `deepseek_web_search` / `deepseek_read_url`。目前只有网页搜索，未实现图片搜索；最多五轮的编排也不等同于 DeepSeek 官方服务端完整搜索策略。

图片识别走模型图片输入，不等同于独立 OCR 或 PDF/Office 文档解析。

## 尚未接入：实测阻塞

| 能力 | 实测结果 | 当前处理 |
| --- | --- | --- |
| PDF / Office 文件输入 | 文档描述的 `type:pdf` 被拒绝；改用 `type:file` 的 URL、内嵌 PDF 数据仍返回 HTTP 400；`/v1/files` 上传也返回 HTTP 400 | 不开放文档上传入口；需要可工作的协议或另接解析服务 |
| 独立 OCR | `/v1/tools/ocr` 按 `purpose=text_recognition`、文件顺序上传 PNG，返回 HTTP 404 | 不开放；需要另一个已验证的 OCR 接口 |
| TTS | `/v1/tools/tts` 返回 HTTP 404 | 不开放；可另选语音合成模型，但尚未实施或验证 |
| 模型安全 | 合法 `safety_check.level=high` 和官方规定应拒绝的非法值均返回 HTTP 200，没有证据证明参数生效 | 不声称审核已开启，需要独立可验证的审核接口或厂商确认 |

知识库问答不在文章列出的直接能力中。本次未实现文档入库、向量检索和 RAG。

| 能力 | 使用方式 | 已完成的验证 |
| --- | --- | --- |
| PDF / Office / 文本文件输入 | 输入栏“文件”→“添加文档用于问答”，解析完成后发送问题 | DOCX、PDF 均完成实际上传、解析及问答；PDF 追问无需重传，37 + 5 回答 42；刷新后保留文件 ID。Excel、PowerPoint 等其他格式按官方协议分配 purpose，未逐一实测 |
| 独立 OCR | “文件”→“识别文字到输入框” | 实际上传 PNG 到 `/v1/tools/ocr`，正确回填 `OCR IRIS-96274 COUNT 83`；空页面、解析不完整按失败处理 |

| 以图搜索 | 官方 Flash 开启“联网搜索”，附图片并要求查找图片来源 | 实际出现 `kind=image_search`，12 条来源含图片 URL；来源面板支持图片预览。目标图片不可访问时明确报错，不宣称搜索完成 |
| 官方服务端搜索与阅读 | 官方 Flash 开启搜索，或直接发送链接 | 官方原生 `deepseek_web_search` / `deepseek_read_url`；保留 `server_tool_calls`、网页签名和来源供追问使用，不占用应用端五轮工具循环 |

文件附件会随消息持久化；编辑消息时保留附件，改用不支持文件的模型会明确提示。每个待发送附件最多 32 MiB、最多 20 个；最终限制仍以官方接口对整段历史的校验为准。移除待发送附件仅取消本地引用，不删除服务器已解析的文件。
