# 七牛网关图片识字及能力补测

日期：2026-11-18。只用本项目 Uni AI / 七牛网关临时 Token，未使用 DeepSeek 官方 Key；对话地址为 `https://api.qnaigc.com/v1/chat/completions`。

## 图片识字：4 个模型实际通过

| 项目目录中的模型 ID | 随机英文数字图片 | 中文订单图片 |
| --- | --- | --- |
| `deepseek/deepseek-v4.1-flash` | 正确 | 正确 |
| `bytedance/doubao-seed-2-1-pro` | 正确 | 正确 |
| `bytedance/doubao-seed-2-1-turbo` | 正确 | 正确 |
| `z-ai/glm-5.3-flash` | 正确 | 正确 |

英文图片预期：`CODE 27839035`、`COUNT 73`。中文图片四行均准确返回：

```text
订单编号：松柏-1999850756
商品：蓝色文件夹
数量：73
金额：1284.60元
```

请求使用 `messages[].content` 中的文字指令和 `{type:'image_url',image_url:{url:图片地址}}`。四个模型来自 `uni_modules/uni-ai-x/sdk/install-qiniu.uts`；这里确认网关这些模型 ID 的实际行为，不推断厂商内部路由。

这是视觉模型识字，尚未验证复杂版面、表格、手写字、坐标输出或批量 OCR 准确率。独立 `/v1/tools/ocr` 接口与此不同。

## 云函数只转发 URL：实际部署验证通过

临时部署云对象 `gateway-capability-probe`，客户端仅传图片 URL；云对象自己取得七牛临时 Token，再将 URL 放入模型请求，没有下载图片、没有重新上传图片。

Doubao Pro 两次测试成功。中文测试 HTTP 200，模型请求耗时 5.515 秒，准确返回上述四行；时间不包括客户端上传及完整交互。测试图片使用云存储可访问的临时地址，私有地址必须有有效访问授权，不能推断任意地址都能读取。

诊断源码保留在 `scripts/gateway-capability-cloud-probe/`。5 个测试文件已通过云端删除接口清理；临时云对象随后成功覆盖部署为仅抛错的禁用实现；回调调用返回云函数异常（平台隐藏了具体异常文案），禁用源码没有获取 Token 或发起请求的代码。云端仍保留该禁用对象，可在控制台删除。

## 对此前说法的补测与修正

| 说法 | 实测证据 | 当前结论 |
| --- | --- | --- |
| 视觉模型能识字 | 上述 4 模型分别识别两张测试图片，均匹配随机内容 | 已验证；已有图片聊天通路可承载，专用“识字”按钮仍走官网，未改接 |
| 图片给 URL 即可，云函数不用下载 | 实际部署云函数，只做一次推理 HTTP 请求，正确识字 | 已验证此链路 |
| PDF/DOCX 给 URL 就能问答 | 4 模型 × 两种文档，测试 `file_url` 及 `file.file_url`，另补多种 PDF 结构；没有一次读出随机文档验证码 | 当前测试协议未测通，不能列为可用。部分 502/超时不能单独证明模型不支持；未穷尽网关全部模型及文档处理服务 |
| 模型安全默认已打开或参数即可开启 | 默认风险请求及 `safety_check.level=high` 均普通拒答；非法 level 也 HTTP 200 | 只能确认该样本模型会拒答，不能确认独立审核或官方安全开关生效 |
| 网关 Token 可直接调七牛独立审核 | `https://ai.qiniuapi.com/v3/text/censor` 返回 401 `bad token` | 现有 Token 不可用；该接口文档要求另外的七牛 AK/SK 签名，本次未持有该凭据，不判断服务本身是否可用 |
| 当前网关能直接 TTS | 本次 `/v1/audio/speech` 返回 404；此前 `/v1/tools/tts` 返回 404 | 当前测试路径未接通，不能声称七牛全部产品没有语音合成 |

文档测试内容为有效生成的 PDF/DOCX：`Verification code: BIRCH-D7DBBDBA3F. Quantity: 47.`。DeepSeek 对第一种文档块返回 HTTP 200，却说明没有收到附件，不能按成功计算。其他请求为 400、502，另一次超时。

独立审核并未在当前业务云对象中主动调用；`data_inspection_failed` 的前端错误提示不等于审核实现。供应商是否另有平台审核，不由此次有限请求推断。
